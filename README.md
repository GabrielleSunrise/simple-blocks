<h3>О проекте</h3>
<p><strong>Simple Blocks</strong> — это удобный инструмент, который позволяет создавать готовые к использованию блоки (карточки, секции, элементы интерфейса) прямо в браузере.</p>
<p>Больше не нужно писать базовый код с нуля — настройте внешний вид и контент, скопируйте код и вставьте его в свой проект!</p>
<h3>Возможности</h3>
<ul>
<li><strong>Гибкая настройка:</strong> меняйте контент и стили «на лету».</li>
<li><strong>Живой предпросмотр:</strong> результат ваших действий отображается мгновенно в блоке превью.</li>
<li><strong>Готовый код:</strong> после настройки вы получаете готовые к копированию HTML, CSS и JS блоки.</li>
<li><strong>Минимум усилий:</strong> идеально подходит для прототипирования или добавления типовых элементов на сайт.</li>
</ul>
<h3>Как пользоваться?</h3>
<ol>
<li>Перейдите на <a href="https://gabriellesunrise.github.io/simple-blocks/">страницу проекта</a>.</li>
<li>Выберите параметры блока в панели настроек.</li>
<li>Просматривайте изменения в блоке предпросмотра.</li>
<li>Скопируйте готовый код (HTML, CSS, JS) из соответствующих полей внизу страницы и используйте его в своем проекте.</li>
</ol>
