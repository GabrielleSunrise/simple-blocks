Привет!

Я генератор стандартных HTML/CSS блоков, которые можно быстро добавить на сайт.
Контент и внешний вид блоков настраиваются.
Результат сразу обновляется в блоке «Предварительный просмотр».
Когда всё готово, просто скопируй на сайт HTML, CSS и JS (если есть) из соответствующих полей.
